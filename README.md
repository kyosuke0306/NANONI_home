# NANONI_home

クラフト発泡酒ブランド「NANONI」の EC サイトです。静的サイト（HTML / CSS / JavaScript）で、ビルドツールや外部ライブラリは使っていません。

NANONI は**愛知県蟹江町**の 24CLUB が企画・販売するブランドです。醸造は委託しており、委託先（株式会社 Story Agent／IB BREWING）は**表示上必要な範囲にとどめ、前面には出さない方針**です。商品一覧の製造者欄と `about.html` のブランド情報表にのみ記載しています。ここを増やさないでください。なお、本品の酒税法上の品名は「ビール」ではなく**発泡酒**です。

ブランド名は「なのに」に由来します。缶に書かれた次の 3 行がブランドの核で、トップページ・商品一覧・`about.html` の 3 か所に載せています（`.nanoni-lines`）。文言を変えるときは 3 か所そろえてください。

```
お酒 "なのに" 無花果
日常 "なのに" 特別
シンプル "なのに" 満足
```

サイトの一番のアピールポイントは**蟹江町の特産品である白いちじく**です。トップページに専用セクション（`#fig`）を置き、`about.html` と `products.html` にも説明を載せています。白いちじくに関する記述（品種名・歴史・収穫時期など）は公開情報を基にしているので、書き換えるときは出典を確認してください。

公開先: https://kyosuke0306.github.io/NANONI_home/

## ⚠️ 販売開始前に必ず対応すること

このサイトは**まだ注文を受け付けられません**。また、**掲載されている事業者情報・価格・免許番号などはすべて記入例**です。

1. **カート / 決済の接続** — 静的サイト単体では決済も在庫管理もできません。Shopify・BASE・STORES などの外部サービスに接続するか、独自にバックエンドを実装する必要があります。
2. **通信販売酒類小売業免許の取得** — 酒類をインターネットで販売するには所轄税務署の免許が必要です。一般の酒類小売業免許とは別のものです。
3. **`legal.html` の記入** — 特定商取引法に基づく表記、酒類販売管理者標識、プライバシーポリシーの内容を実際の情報に差し替えてください。
4. **商品情報** — 商品は `NANONI -white-` の 1 点で、記入は完了しています。缶の表示（品名・原材料名・内容量・アルコール分・保存方法・製造者・企画）に加え、スタイル（Hazy Wheat Ale）・IBU・使用ホップ・味わいの説明も掲載済みです。紹介文は缶の「What is NANONI -white-」の文面を使っています。
5. **販売事業者の詳細** — 販売主体は 24CLUB です（記入済み）。所在地・電話番号・免許番号など残りの欄は `legal.html` で記入待ちです。醸造者（株式会社 Story Agent／IB BREWING）は販売者ではないので、特商法の表記に書かないでください。
6. **送料の金額** — 常温便 ¥800 / クール便 ¥1,100 は**仮の金額**です。実際の配送業者の料金に合わせて `index.html`・`guide.html`・`legal.html` の 3 か所を直してください。
7. **`about.html` / `guide.html` の記入** — 事業者情報、返品条件などを実際の運用に合わせてください。

### 保存方法の書き方について

保存方法は缶の表示どおり「10 度以下で冷蔵保存」で統一しています。本品は熱処理済みで常温でも保管できますが、**サイトには常温保存可と書かない方針**です（缶の表示と食い違うため）。配送は常温便とクール便の両方を選べますが、クール便を推奨する書き方にしています。

法令上の要件があるため、公開前に専門家の確認を受けることをおすすめします。

## 年齢確認について

酒類を扱うため、初回アクセス時に 20 歳以上かを確認するモーダルを表示します（`assets/js/main.js`）。

- 「はい」を選ぶと `sessionStorage` に記録します。同じタブで見て回る間は再表示しませんが、**タブやブラウザを閉じると記録が消え、次の訪問時にまた確認します**
- ずっと記憶させたい場合は、`assets/js/main.js` の `sessionStorage` を `localStorage` に書き換えてください（その場合、一度「はい」を押すと二度と表示されません）
- JavaScript が無効な環境ではモーダルが表示されません（コンテンツは閲覧できます）
- **これは自己申告による簡易確認です。** 実効性のある年齢確認は、決済プラットフォーム側の仕組みと、配達時の身分証確認で担保してください

## ローカルで確認する

```bash
python3 -m http.server 8000
# または
npx serve .
```

http://localhost:8000 を開きます。年齢確認モーダルをすぐ再表示したい場合は、開発者ツールで `sessionStorage.removeItem('nanoni:age-verified')` を実行するか、タブを閉じて開き直してください。

## 公開の仕組み

`main` ブランチへ push すると GitHub Actions が走り、リポジトリの内容がそのまま GitHub Pages へデプロイされます。手動実行は Actions タブの **Deploy to GitHub Pages** → Run workflow から行えます。

リポジトリの Settings → Pages → Source は **GitHub Actions** に設定済みです。

## 編集のしかた

- **配色を変える**: 缶とブランドマークに合わせ、白・黒・グレーで統一しています（色を持つのは注意喚起の `--danger` だけです）。変更する場合は `assets/css/style.css` 冒頭の `:root` にある変数を書き換えます。ダークモード用の値は `@media (prefers-color-scheme: dark)` 内にあります。`--accent` はボタンや強調に使う色で、現在は本文と同じ黒（ダークモードでは白）です。
- **商品を増やす**: `products.html` の商品カードの下に、コメントアウトされたテンプレートを置いてあります。これをコピーしてコメントの外に出し、缶の色・スタイル・商品名・説明・スペック・価格を書き換えてください。グリッドは自動で折り返すので CSS の変更は不要です。トップページにも載せたい場合は `index.html` の `.product-grid` に同じ要領で追加します（見出しタグが `h3` である点だけ異なります）。
- **ブランドマーク**: `assets/img/brand-mark.svg`（ヘッダー・年齢確認・フッターで使用）と `assets/img/favicon.svg`（ブラウザのタブ用、背景付き）の 2 つです。元画像をベクター化したものなので、拡大しても輪郭がぼけません。黒一色のため、ダークモードでは CSS の `filter: invert(1)` で明色に反転させています（`.brand-mark`）。大きさは使う場所ごとに `.logo-icon` / `.age-gate-mark` / `.footer-mark` で指定しています。
- **写真**: `assets/img/` に 3 点あります。`nanoni-white.jpg`（缶のスタジオ写真、商品カード用・2:3）、`nanoni-white-glass.jpg`（グラスに注いだところ）、`fig-leaf.jpg`（仕込みに使った白いちじくの葉、4:3）。文章と写真を横に並べるレイアウトは `.media-split`、中央に置く縦長写真は `.figure-narrow` です。
- **商品画像**: `assets/img/nanoni-white.jpg`（900×1350、約 70KB）を使っています。差し替えるときは同じ縦横比（2:3）で書き出すと、レイアウトを変えずに済みます。写真がまだ無い商品には、CSS で描いた缶のプレースホルダー（`.can`、`--can-color` で色指定）が使えます。使い方は `products.html` のコメントに書いてあります。
- **ヘッダー / フッター**: 各 HTML ファイルに直接書かれています。共通部分を変更する際は全ページの修正が必要です。ページ数が増えるようなら静的サイトジェネレーターの導入を検討してください。

## ページごとの役割（重複を避ける方針）

同じ内容を複数ページに書かないよう、話題ごとに置き場所を決めています。追記するときは正の置き場所に書き、他ページからはリンクしてください。

| 内容 | 正の置き場所 | 他ページ |
| --- | --- | --- |
| 「なのに」3 行 | トップのヒーロー、`about.html`（由来の説明つき） | 他には置かない |
| 白いちじくの詳細（品種・歴史・街道） | `about.html` | トップは 2 段落の要約＋リンク |
| 葉を使う理由 / 商品名の由来 | `about.html` | 商品一覧はリンクのみ |
| 味わい・商品仕様 | `products.html` | トップのカードは 1 行 |
| 活動の記録 | `activity.html` | 他ページには置かない |
| お取り扱い店舗・在庫状況 | `shops.html` | 他ページはリンクのみ |
| 送料・配送・支払い・FAQ | `guide.html` | トップは要約＋リンク、`legal.html` は法令上必要なため記載 |
| 保存方法 | `products.html` の商品情報 | ガイドの FAQ は 1 行＋リンク |

## 在庫状況と店舗の更新

在庫が復活したときに直す場所は次のとおりです。品切れ表示は `.shop-status` クラスです。

- `shops.html` — 冒頭の在庫のお知らせと、各店カードの「現在品切れ中」
- `products.html` — 商品カードの「現在品切れ中／入荷予定あり」と、ご購入手続きの案内
- `index.html` — 商品カードの「現在品切れ中／入荷予定あり」

店舗を追加するときは `shops.html` の `.card-grid` に `<li class="card">` を足してください。グリッドは自動で折り返します。ヘッダーのナビ項目は 6 つあり、62rem 未満でハンバーガーメニューに切り替わります。項目を増やす場合はこの幅も見直してください。

## イラスト

線画のイラストを SVG で HTML に直接書いています。画像ファイルではないので、`fill="none" stroke="currentColor"` により配色に自動で追従し、拡大しても輪郭が崩れません。

- `guide.html` のお支払い方法 3 枚（カード / 銀行 / 代金引換）— `.card-icon`
- `index.html` のご注文について（保冷ボックスと雪の結晶）— `.illust`

雪の結晶の座標は三角関数で算出したものです。描き直す場合は、腕の途中から**外向き**に枝を出してください。先端から内向きに引くと矢印に見えます。

## 外部リンク

Instagram（https://www.instagram.com/nanoni_kanie ）を、全ページのフッター下部（アイコン）、`guide.html` のお問い合わせ（アイコン付きボタン）、`about.html` のブランド情報表（テキスト）に置いています。
